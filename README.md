# Battle Arena 3D Multiplayer

Three.js browser 3D third-person multiplayer battle starter using Node.js and WebSocket.

Features: room codes, up to 20 players, 3D arena, third-person camera, movement, melee, fictional energy weapons, health, kills, respawn, 3-minute match, late joining, mobile controls and desktop controls.

Run: `npm install` then `npm start`.
Render: Root blank, Build `npm install`, Start `npm start`, branch `main`, Free instance.
Three.js is loaded from jsDelivr in the browser.
